Huefy
Find your perfect colors.

Huefy is a fully client-side color palette generator packed into a single HTML file. Browse 350 curated colors, generate palettes, save favorites, share via URL, and export in multiple formats — no backend, no login, no dependencies.

HuefySingle FileNo BackendZero Dependencies

Features
Palette Generator
Generate random palettes from a curated library of 350 colors
Lock individual colors to keep them during regeneration
Add and remove colors freely
Drag and drop to reorder
Built-in color picker per card
Copy HEX, RGB, and HSL values with one click
Color Library
350 hand-picked colors across 8 families: Red, Orange, Yellow, Green, Blue, Purple, Pink, Brown
Each family progresses from very light to very dark
Instant search by name, hex code, or family
Filter by color family
Click any swatch to add it directly to your palette
Templates
15 built-in curated palettes: Sunset, Ocean, Forest, Midnight, Coffee, Candy, Sakura, Desert, Nature, Minimal, Luxury, Cyberpunk, Retro, Vibrant, Arctic
One-click load into the generator
Favorites
Save unlimited palettes to localStorage
Load saved palettes instantly
Remove individual favorites
Persists across browser sessions
Sharing
Generate shareable URLs with palette encoded in query params
Example: ?palette=FF6B6B-FFD93D-6BCB77-4D96FF-845EC2-FF6348
Auto-loads palettes from shared links on page visit
One-click copy share URL
Exports

Toggle between light and dark themes
Respects system preference on first visit
